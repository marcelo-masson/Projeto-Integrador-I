# Simulador de Sistema de Alarme Industrial

Projeto desenvolvido para a disciplina de **Projeto Integrador I** do curso de Engenharia de Computação. O objetivo é criar um sistema simples de monitoramento de segurança industrial através do desenvolvimento de lógica digital, álgebra booleana, simulação em circuito no Logisim e implementação em Assembly MIPS utilizando o simulador MARS.

## Descrição do Projeto

Uma indústria necessita de um sistema básico de segurança para monitorar acesso e movimentação em áreas restritas. O sistema conta com três sensores de entrada e aciona um alarme sonoro/visual caso uma condição de risco seja detectada com o sistema ativado.


---

## Regras do Sistema

O alarme (**S**) só deverá ser ativado quando:
1. O sistema estiver **ligado**
2. Houver alguma situação de risco: **porta aberta** **OU** **movimento detectado** .
